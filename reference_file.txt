Below is a detailed specification of Cooklang syntax and structure:

### Ingredients
- Ingredients are tagged using the `@` symbol.
- Quantities are enclosed in `{}` after the ingredient name.
- Units of measurement are specified with `%` following the quantity.

Examples:
```
Add @sugar{2%cups} to the bowl.
Sprinkle @salt{} to taste.
```

### Steps
- Each paragraph represents a single cooking step.
- Steps are separated by empty lines.

Example:
```
Chop @onion{1}.

Fry the @onion{} in a #pan{} until golden brown.
```

### Cookware
- Cookware is tagged using the `#` symbol.
- Multi-word cookware names can be enclosed in `{}`.

Examples:
```
Heat water in a #pot{}.
Use a #wooden spoon{} to stir.
```

### 4. Timers
- Timers are defined with the `~` symbol.
- Timers can include a name and duration.

Examples:
```
Bake for ~{30%minutes}.
Boil @eggs{2} for ~eggs{7%minutes}.
```

### 5. Metadata
- Metadata is included as YAML front matter at the beginning of the file, enclosed by `---`.
- Tags should be one per line with a dash in front. You should always include tags.
- Make all tag values be all lowercase characters.

Example:
```
---
title: Chocolate Cake
servings: 8
author: Jane Doe
prep time: 15 minutes
cook time: 30 minutes
tags:
  - american
  - dessert
  - oven
---
```

### Sections and Comments
- Notes: Use `>` to add additional information or tips.
- Sections: Define sections of recipes with headers like `==Section Name==`.

Examples:
```
> This recipe works best with fresh ingredients.

==Sauce==
Mix @tomato paste{1%cup} with @water{1/2%cup}.
```

### Short-hand preparations

Many recipes involve repetitive ingredient preparations, such as peeling or chopping. To simplify this, you can define these common preparations directly within the ingredient reference using shorthand syntax:

Mix @onion{1}(peeled and finely chopped) and @garlic{2%cloves}(peeled and minced) into paste.
